`vars` are public, non-secret values. Structured-clone-compatible JSON enters `env`.

```ts
import { bindings, defineConfig } from "cf/config";

export default defineConfig({
  worker: {
    name: "hello-typescript",
    entrypoint: "src/index.ts",
    env: {
      GREETING: bindings.text("Hello from TypeScript"),
    },
  },
});
```

```ts
export default {
  fetch(_request: Request, env: Env): Response {
    return new Response(env.GREETING);
  },
} satisfies ExportedHandler<Env>;
```

Regenerate types after changing vars:

cf writes literals into `.cloudflare/types/` (for example `GREETING: "Hello from TypeScript"`). Bundles do not contain vars; development and deployment inject them.

## Compatibility

| Topic                                      | Cloudflare                                                                                                    | open-compute                                                |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Public strings/JSON on `env`, not secrets  | Yes — [Environment variables](https://developers.cloudflare.com/workers/configuration/environment-variables/) | Yes                                                         |
| cf `[vars]` TOML                           | Yes                                                                                                           | Not provided                                                |
| Dashboard editor / cf environments product | Yes                                                                                                           | Not provided                                                |
| Unknown top-level keys                     | May be ignored                                                                                                | Fail the whole project config                               |
| Where secrets live                         | Secrets product                                                                                               | [secrets](/docs/workers/configuration/secrets/), not `vars` |
